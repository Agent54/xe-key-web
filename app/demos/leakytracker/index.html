    Beyond the five: two known gaps

    No policy a web page can set switches off WebRTC or stops a preconnect, so in a stock browser these two get past the sandbox. They are here so the gap is measured instead of assumed away. Closing them is the browser's job. The form attack above shows the second one by accident: the browser opens a socket for the form's navigation before the policy stops it, so the tracker sees a connection with nothing in it.

    What still works

    The sandbox is not a blank page. The app's own script, style and images load, it draws, it stores data locally, and you could click straight into it without installing anything or answering a prompt. The header image above is this app's own file, allowed by img-src 'self'; the tracking pixel is the same kind of request to someone else's server.
